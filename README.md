# KERAMO ART — სანიჟარეების გალერეა

ერთგვერდიანი, სტატიკური საიტი KERAMO ART-ის განხორციელებული პროექტების გალერეისთვის. გადახდა/კალათა არ არის — საიტი შთაგონება-შერჩევისთვისაა, შემდეგ ყველა ნიჟარა ინდივიდუალურად მზადდება (ბრიგადის მიერ ადგილზე აზომვის შემდეგ).

## სტრუქტურა

```
index.html         — მთავარი გვერდი
css/style.css       — სტილები
js/products.js      — 17 რეალური პროექტის მონაცემები (სახელი, კატეგორია, მასალა, ზომა)
js/app.js           — ფილტრაცია, პროექტის პანელი, საკონტაქტო ფორმა
assets/logo-mark.svg — ლოგოს ნიშანი (ბრენდის ფოტოდან ხელახლა აგებული, სუფთა SVG)
assets/sinks/*.jpg   — რეალური ფოტოები (17 ცალი), თქვენ მიერ მოწოდებული
```

## რისი შევსებაა საჭირო გაშვებამდე

1. **ელ.ფოსტა** — `index.html`-ში `#contact` სექციაში და `js/app.js`-ში `mailto:info@keramoart.ge` ჯერ კიდევ placeholder-ია. შეცვალეთ რეალური ელ.ფოსტით.
2. **სამუშაო საათები** — `#contact` სექციაში, placeholder-ია.
3. **ახალი პროექტების დამატება** — დაამატეთ ახალი ობიექტი `js/products.js`-ში `PRODUCTS` მასივში (იგივე სტრუქტურით: `id`, `name`, `category`, `material`, `color`, `size`, `washer`, `note`) და ფოტო შეინახეთ `assets/sinks/<id>.jpg`-ში.
4. **დომენი** — საიტი მზადაა GitHub Pages-ზე გასაშვებად (Settings → Pages → Deploy from branch → main). საკუთარი დომენის მიბმის შემდეგ დაამატეთ `CNAME` ფაილი root-ში.
