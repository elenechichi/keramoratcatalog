# KERAMO ART — სანიჟარეების კატალოგი

ერთგვერდიანი, სტატიკური საიტი KERAMO ART-ის (ფაიფურისა და კერამოგრანიტის ნიჟარები) პროდუქციის კატალოგისთვის. გადახდა/კალათა არ არის — საიტი მხოლოდ დათვალიერება-შერჩევისთვისაა, შეკვეთა მიდის ფორმით ან პირდაპირი კონტაქტით.

## სტრუქტურა

```
index.html         — მთავარი გვერდი
css/style.css       — სტილები
js/products.js      — პროდუქტების მონაცემები (placeholder)
js/app.js           — ფილტრაცია, პროდუქტის პანელი, საკონტაქტო ფორმა
assets/logo-mark.svg — ლოგოს ნიშანი (ბრენდის ფოტოდან ხელახლა აგებული, სუფთა SVG)
assets/sinks/*.svg   — ნიჟარების placeholder ილუსტრაციები (24 ცალი)
assets/brand-reference/ — თქვენ მიერ მოწოდებული ლოგოს ფოტო, მხოლოდ რეფერენსისთვის
scripts/gen_assets.py — სკრიპტი, რომელმაც დაგენერირა products.js და placeholder ილუსტრაციები
```

## რისი შევსებაა საჭირო გაშვებამდე

1. **რეალური ფოტოები** — `assets/sinks/*.svg` placeholder ილუსტრაციებია. შეცვალეთ რეალური პროდუქტის ფოტოებით იგივე ფაილის სახელებით (`assets/sinks/onda-01.jpg` და ა.შ.) და განაახლეთ გზა `js/app.js`-ში ფუნქციაში `productImg()`.
2. **პროდუქტების სია** — `js/products.js`-ში 24 placeholder მოდელია (სახელი, მასალა, ფერი, ზომა). შეცვალეთ რეალური მონაცემებით ან დაამატეთ/წაშალეთ მოდელები იგივე სტრუქტურით.
3. **საკონტაქტო ინფორმაცია** — `index.html`-ში `#contact` სექციაში: ტელეფონი, ელ.ფოსტა, Instagram. ასევე `js/app.js`-ში `mailto:info@keramoart.ge` შეცვალეთ რეალური ელ.ფოსტით.
4. **დომენი** — საიტი მზადაა GitHub Pages-ზე გასაშვებად (Settings → Pages → Deploy from branch → main). საკუთარი დომენის მიბმის შემდეგ დაამატეთ `CNAME` ფაილი root-ში.

## ადგილობრივად გახსნა

უბრალოდ გახსენით `index.html` ბრაუზერში — backend არ სჭირდება.

## მონაცემების თავიდან გენერაცია

თუ გსურთ placeholder მონაცემების/ილუსტრაციების ხელახლა გენერაცია სტრუქტურის შეცვლის შემდეგ:

```
python3 scripts/gen_assets.py
```
