# KERAMO ART — კერამო არტის აბაზანის ნიჟარები

საიტი: https://keramoart.com.ge · ადმინ პანელი: https://keramoart.com.ge/admin/

## სტრუქტურა
- `index.html`, `css/style.css`, `js/app.js` — საჯარო საიტი (ანიმაციები, კატალოგი, ფასები, კალკულატორი)
- `js/data.js` — მონაცემები Supabase-დან; თუ ის არ არის დაკავშირებული, გამოიყენება `js/products.js`
- `js/config.js` — Supabase URL და anon key
- `admin/` — ადმინ პანელი (მოდელები, ფოტოები, ზომა, ფასი, კატეგორიები, კონტაქტები)
- `supabase/schema.sql`, `supabase/seed.sql` — ბაზის სტრუქტურა და საწყისი 17 მოდელი
- `assets/fonts/` — BPG Nino Mtavruli Bold და AR Archy SemiBold (ქართული სიმბოლოები + ციფრები)
